# ECG工作区使用说明

<!-- topic:overview -->
本系统是ECG记录分析与证据复核原型，不是临床诊断系统。先选择或上传一条记录，查看信号；再按需查询窗口与RR，最后核对波形证据。模型分数不是概率。

<!-- topic:batch -->
“ECG批量错分复核”用于找出模型预测与数据标签不一致的记录。误报是标签正常、预测异常；漏报是标签异常、预测正常。侧栏选择“批量复核”，选择报告、筛选类别、按分数排序，再选择记录打开波形或单条分析。记录数量以所选报告为准。它不自动修改标签，也不作疾病诊断。打开单条分析会校验数据和版本；有兼容历史则复用，否则由用户明确点击后运行本地分析。

<!-- topic:signal -->
“查看信号”（原“信号分析”）展示输入与重构叠加、绝对重构差和模型组合分数。可切换导联、定位候选窗口。模型组合分数可能为负，与绝对重构差含义不同。问答下的“查看波形”读取被引用工具证据的导联与采样点，不是从文字猜位置；点击不发出LLM请求。

<!-- topic:chat -->
“向本记录提问”（原“当前样本问答”）支持查询窗口统计、RR与历史窗口。当前分析范围绑定一条分析；所选批次范围支持按分类检查兼容历史并读取已有摘要，不支持任意跨记录计算。发送数据问题前需允许网关访问。示例：查看V2最后1.2秒，给出起止采样点、均值和最大值。数值查询以实际工具结果为准。使用帮助问题由本地说明回答，不需调用网关。

<!-- topic:details -->
“查看分析依据”（原“分析详情”）查看导联排名、候选区域筛选过程、模型判定规则及RR对齐。没有候选区域只表示当前提取规则没有返回窗口，不能据此排除疾病。configured只表示阈值配置有效，不证明跨记录版本匹配。

<!-- topic:export -->
“导出记录”下载当前分析或会话界面提供的导出文件。先按页面按钮准备导出，再下载。不是完整原始数据备份，也不会导出所有历史分析。请以导出页面实际提示的内容为准。

<!-- topic:history -->
侧栏“历史记录”可搜索名称或分析ID片段、按数据样本索引筛选，支持打开、重命名、归档与删除。“数据样本索引”不是患者编号；上传记录没有编号时留空。同时填写名称与编号时必须同时匹配。归档可恢复；永久删除会删除该分析保存的波形、模型结果及关联对话，不删除原始数据文件和评测报告。有待完成请求时先结束本地等待。其他会话中的旧引用可能因此失效。

<!-- topic:upload -->
若侧栏提供上传入口，按该入口提示上传CSV或NPZ格式的12导联数据。当前只接受500Hz，完整导联顺序需可校验，不自动补齐缺失导联或转换任意采样率。模型输入是4800点片段。原始上传信号的滤波与训练流程一致性仍未完成验证，不能把任意上传结果当作经验证的测量。

<!-- topic:guide -->
侧栏“开始 / 重新打开步骤指引”提供单条和批量两条路线。成功打开记录、保存回答和点击波形会推进对应步骤；看图与筛选由用户确认。可以上一步、跳过、退出。指引不会替用户发请求或运行模型。首次展示状态按本机工作区保存，不是多用户账号状态。
