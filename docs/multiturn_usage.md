# 同一样本多轮问答

安装后从项目根目录运行：

```bash
python -m unittest tests.test_conversation tests.test_conversation_export
python -m unittest tests.test_conversation_agent
python -m streamlit run app_ecg.py --server.address 127.0.0.1 --server.port 8505 --browser.gatherUsageStats false
```

8504 已被占用时可以使用8505。浏览器打开 http://127.0.0.1:8505 。若需要继续使用8504，在原先启动服务的终端按 Ctrl+C 后重启。不要盲目终止未知进程。网关环境变量需在启动服务前设置。

## 验收

1. 样本0→本地分析。
2. 提问“心率依据哪些 RR？请查询并说明保留、排除数量与计算依据。”
3. 追问“其中最长的间隔是哪一个？给出两个峰的坐标。”期望重查RR，样本0当前结果最长1.028秒，片段峰坐标3261–3775；以本次工具结果为准。
4. 再问“它有没有被排除？为什么？”期望理解上轮对象，并查询筛选标记和参数，不将历史文字当新证据。
5. 检查每轮证据和轨迹；失败仍显示，之前成功回答不丢失。
6. 导出JSON/Markdown，检查问题顺序、分析ID、各轮状态与证据。
7. 切换样本1：旧会话消失，需重新本地分析；问“刚才那个间隔呢？”应提示上下文不足，而不是沿用样本0数据。

## 行为和边界

- 同一分析会话保存最多20轮，最近最多3轮成功且结构通过的完整问答作为背景；历史JSON最多9000字符，过长轮次不截取成残缺事实。更早内容仍显示/导出，但模型未必记得。请在问题中明确重要对象。
- ConversationGateway 对现有模型请求增加历史背景，不覆盖 evidence_agent.py 或修改其校验器。每轮仍是原有 LangGraph 工具循环。
- 历史不携带可直接复用的证据库；证据引用必须通过本轮摘要或工具获取。历史文字可能错误，不能证明当前结论。
- 成功/失败轮次均保存；失败内容不进入后续模型上下文。每轮最多4次模型请求、6次工具执行，无自动重试。
- 重新分析（即使同一样本）、切换样本、清空对话均创建新会话。旧请求返回受分析ID、会话ID和请求ID检查。
- 刷新/服务重启可能丢失内存会话；导出不是自动恢复。没有跨用户账户、数据库持久化或公网部署。
- UI发送的是当前问题加历史背景，仍需外发勾选。JSON含完整会话问题和响应，配置使用既有白名单，不写Token。
- 测试 test_conversation_agent 使用模拟网关验证两轮Graph集成，不代表真实模型追问正确率。真实验收需在用户环境执行。

## 本次文件

- app_ecg.py：多轮聊天、清空、样本隔离和导出入口。
- src/agent/conversation.py：轮次状态、有限历史、网关适配器。
- src/reporting/conversation_export.py：每轮复核并导出完整会话。
- tests/test_conversation*.py：隔离、历史、导出和模拟Graph集成测试。

本地开发工具未安装langgraph，已执行14项会话/导出单元测试；Graph集成脚本随安装包提供，需在现有项目环境运行。未调用真实网关。
