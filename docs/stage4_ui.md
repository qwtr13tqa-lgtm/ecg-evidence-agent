# 统一页面与导出

启动：
```
python -m streamlit run app_ecg.py --server.address 127.0.0.1 --server.port 8504 --browser.gatherUsageStats false
```
使用已有数据、权重、环境依赖。新增页面，不覆盖旧页面或后端。
本地分析与导出不需要 API Key。按需提问时使用当前终端 ECG_API_KEY、ECG_BASE_URL、ECG_MODEL；在启动进程前设置。仅导出允许的模型配置字段，不读取或导出完整环境变量。

流程：选样本→本地分析→波形/模型证据/RR事实→可选提问→准备导出→下载JSON及Markdown。
波形横轴为裁剪片段秒数；候选峰只标记在提取器所用导联，非全部导联重复标记。不能从图上确认检测准确性。
显示当前样本、analysis_id、提交过的问题。改变问题输入框不会改写已保存问题；重新提问清除旧回答及旧导出。切换样本、重新分析也清除旧状态。请求结果检查analysis_id/request_id后才接收。
资源与分析存储沿用本地原型；面向单用户localhost，不是多租户权限系统。存储记录被释放时提示重新分析。

JSON：分析摘要、来源、RR核算、问题/请求ID、模型配置、Agent原始回答/知识/证据/轨迹、原始校验及导出时独立校验。无完整原始波形、重构、error_map数组。
Markdown：阅读版计算事实、问题、原始回答、知识来源、分析来源；完整轨迹在JSON内。
失败Agent输出可导出，状态no_completed_draft；结构不合格原始草稿保留并标记failed，不能看作通过报告。跨分析引用拒绝导出。有限JSON检查拒绝NaN。
下载仅由用户点击按钮生成，不自动外发。配置白名单避免导出API Key；问题、引用文本与分析来源本身会包含在下载文件中。
未评估自由文本语义/医学正确性。本页是当前样本问答记录，不冒充已完成全部测量的临床报告。

测试：
```
python -m unittest tests.test_analysis_export
```
本地冒烟：先分析样本0，准备并下载；切换样本1确认旧答案/下载消失；重新分析后下载的analysis_id应为新值。可选问题请求仍走既有网关，不在离线测试执行。
