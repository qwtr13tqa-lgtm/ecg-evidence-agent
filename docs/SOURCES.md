# 代码来源与贡献范围

更新：2026-10-04。

## 项目主线

本项目重点是 ECG 证据复核 Agent：将自然语言请求转为受约束的工具查询与集合操作，管理证据、对象范围、调用预算及失败恢复，并与波形复核界面联动。

底层信号分析使用 SGRF-Net。根据项目作者说明，SGRF-Net 基于 TSRNet 项目修改，不应将完整底层网络描述为完全从零独立实现。

## 本项目的工程工作

本项目开发工作集中于以下内容；并不表示这些内容中的所有依赖或代码均为独立原创：

- 本地模型与信号统计工具的统一接口、分析记录与版本匹配。
- 单样本受限工具循环、跨轮窗口对象恢复、结构化证据引用校验。
- 批次集合筛选、排序、聚合及条件参数依赖绑定。
- 跨记录复核、调用预算、上下文投影、有限错误修复与规划超时恢复。
- Streamlit 波形联动、历史管理、导出及失败反馈。
- 固定流程、一次规划和 Agent 的开发评测与失败案例回归。

PyTorch、Streamlit、LangGraph、OpenAI Python SDK 等第三方依赖各自遵循其许可证。本项目不对第三方代码重新授予统一 MIT 许可。
